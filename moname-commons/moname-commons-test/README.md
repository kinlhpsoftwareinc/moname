## moname-commons-test

Module for common test abstractions.

### Building from source

```sh
../../mvnw [--activate-profiles <PROFILES>] [--also-make-dependents] \
--batch-mode --no-transfer-progress --projects com.kinlhp:moname-commons-test \
[--threads <THREADS>] --update-snapshots clean verify
```
