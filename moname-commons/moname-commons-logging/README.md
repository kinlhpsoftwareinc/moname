## moname-commons-logging

Module for common Logback logging utilities.

### Building from source

```sh
../../mvnw [--activate-profiles <PROFILES>] [--also-make-dependents] \
--batch-mode --file .. --no-transfer-progress \
--projects com.kinlhp:moname-commons-logging [--threads <THREADS>] \
--update-snapshots clean verify
```
